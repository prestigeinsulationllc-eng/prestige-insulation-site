R-13 FAQ

Common questions about R-13.

Can R-13 be used in climate zones 4–8?

For above-grade walls in cold climates, codes typically require R-20 or higher — which means R-13 alone doesn't satisfy code for exterior walls in zones 4+. However, R-13 can be used as part of a continuous insulation assembly, or for interior partition walls, in any climate zone.

What's the difference between R-13 and R-15?

R-15 is the high-density version for 2×4 cavities — same thickness, higher density, better thermal performance. Both fit the same framing. If your spec or code requires R-15, ask about it when you call.

Do you have kraft-faced and unfaced versions?

Yes. Kraft-faced is for exterior walls and basement walls. Unfaced is for interior walls, retrofit, and double-layer attic applications. Specify when you call.
